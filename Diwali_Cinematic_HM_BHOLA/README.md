# 🪔 Diwali Cinematic — HM BHOLA

A fully procedural, cinematic Diwali film made with **pure Python** (pygame + numpy).
No images, no audio files — every pixel and every sound is generated by code.

## The story (60 seconds, 9:16 reel format)
1. **Darkness → one diya** — a single flame is lit, then the courtyard lights up slowly, diya by diya.
2. **The rangoli blooms** — a 100+ layer mandala of coloured powder pours outward from the centre.
3. **Fireworks** — rockets climb behind the temple skyline: peony, ring, willow, crackle… and a heart.
4. **Grand finale** — one huge golden burst, and the sparks fly together to form **HAPPY DIWALI**.

Cinematic tricks used: dynamic light-map (diyas & fireworks really light the floor), tilt-up/pull-back
camera, camera shake on explosions, bloom, vignette, film grain, sky lanterns, glowing temple windows,
and a procedural soundtrack (temple bells per diya, drone pad, whooshes, booms, crackles, golden chord).

## Setup
```
pip install pygame numpy imageio-ffmpeg
```
(`imageio-ffmpeg` is only needed for exporting the MP4.)

## Run
```
python main.py                 # play live, with sound
python main.py --quality low   # lighter effects for slower PCs
python main.py --render        # export Diwali_Cinematic_HM_BHOLA.mp4 (1080x1920, with audio)
python main.py --render my.mp4 # custom file name
```
Keys while playing: `ESC` quit · `SPACE` restart · `F` fullscreen

Tip for Reels: use `--render` — the export is always smooth 30 fps, no matter how fast your PC is.

## Customise (everything is in `config.py`)
- `BRAND` — footer text · `T_TEXT` — when the finale happens
- `make_fireworks()` — the whole firework schedule (time, position, type, colours)
- Title words are in `Title` inside `world.py` (`'HAPPY'`, `'DIWALI'`, subtitle)
